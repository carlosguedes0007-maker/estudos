## 📖 Sobre o Meu Caderno de Estudos & Laboratórios

Este repositório (**Estudos**) é o meu **caderno pessoal de aprendizado contínuo, resumos teóricos e laboratório vivencial de código (*My Developer Study Notes & Tech Lab*)**. Em vez de planos de aula ou currículos estáticos, aqui eu registro, documento, resumo e coloco à prova tudo o que estou estudando sobre arquitetura de software, cibersegurança, automação de sistemas e desenvolvimento web moderno.

Para organizar minha rotina e conectar os estudos aos meus projetos reais (como o *ERP Biblioteca*, *Color Harmony Engine*, *CommitCraft CLI*, *DevEnv Doctor* e laboratórios de *Entropia e Cibersegurança*), estruturei meu caderno em **11 Trilhas de Estudo**. Cada trilha está dividida em **7 Módulos de Investigação Prática**, somando mais de **770 Anotações e Resumos** com teorias de referência, macetes corporativos e experimentos de código autônomos que implementei para fixar cada conceito.

## 🏗️ Como Organizo Meu Conhecimento (Estrutura 7x10)

Para garantir um aprendizado sólido e cobrir desde os fundamentos teóricos até a aplicação industrial, dividi cada uma das 11 trilhas na arquitetura de **7 Módulos de Investigação**, onde cada módulo reúne exatamente **10 Tópicos Práticos**:

```text
estudos/
├── HTML/
│   ├── CADERNO_DE_ESTUDOS.md                  # Meu índice detalhado e anotações dos 70 Tópicos
│   ├── Modulo_01_Iniciante_Fundamentos/       # Tópicos 01 a 10: Semântica, DOCTYPE e Tags Essenciais
│   ├── Modulo_02_Formularios_e_Interatividade/ # Tópicos 11 a 20: Validações Nativas, Modais e Acessibilidade
│   ├── Modulo_03_Multimidia_e_Graficos/       # Tópicos 21 a 30: SVG Nativo, Canvas 2D/3D e Open Graph SEO
│   ├── Modulo_04_Web_APIs_e_Armazenamento/    # Tópicos 31 a 40: LocalStorage, IndexedDB e Web Workers
│   ├── Modulo_05_Acessibilidade_WCAG_ARIA/    # Tópicos 41 a 50: WAI-ARIA, Screen Readers e APCA
│   ├── Modulo_06_Performance_e_Web_Components/# Tópicos 51 a 60: Shadow DOM, Custom Elements e Core Web Vitals
│   └── Modulo_07_Projetos_Reais_e_Maestria/   # Tópicos 61 a 70: Projeto Final de Landing Page Acessível
├── CSS/
│   ├── CADERNO_DE_ESTUDOS.md                  # Meu caderno de Design Systems e Arquitetura Visual
│   ├── Modulo_01_Fundamentos_e_Selecão/       # Tópicos 01 a 10: Especificidade, Box Model e Variáveis
│   └── ... (Módulos de Flexbox, Grid Layout, Design Tokens, Glassmorphism, Animações e BEM)
├── LOGICA DA PROGRAMACAO/
│   ├── JavaScript/                            # 7 Módulos / 70 Tópicos de JS ES6+ e Big O Notation
│   ├── TypeScript_React_NextJS/               # 7 Módulos / 70 Tópicos de Stack Corporativo e ERP
│   ├── Python/                                # 7 Módulos / 70 Tópicos de Automação e Entropia de Senhas
│   ├── C/                                     # 7 Módulos / 70 Tópicos de Ponteiros e Alocação Dinâmica
│   ├── JAVA/                                  # 7 Módulos / 70 Tópicos de JVM, Streams e Design Patterns
│   └── PHP/                                   # 7 Módulos / 70 Tópicos de PDO, MVC e Autoloading PSR-4
```

Dentro de cada pasta de módulo (`Modulo_XX_...`), você encontrará:
1. `ANOTACOES_DO_MODULO.md`: Meus resumos teóricos dos fundamentos, macetes que aprendi e anotações técnicas consolidadas.
2. `experimento_pratico.[ext]`: Meu código de teste autônomo na linguagem nativa (`.html`, `.css`, `.js`, `.py`, `.c`, `.java`, `.php`, `.sql`, `.sh`) pronto para compilar ou executar no terminal ou navegador.

## 🚀 Como Executar Meus Experimentos Práticos

1. **Clone o Meu Caderno no seu Terminal:**
   ```bash
   git clone https://github.com/carlosguedes-dev/estudos.git
   cd estudos
   ```

2. **Para Experimentos Web (HTML5, CSS3, JavaScript):**
   - Abra a pasta no Visual Studio Code e utilize a extensão **Live Server**.
   - Ou abra os arquivos `experimento_pratico.html` diretamente em seu navegador preferido.

3. **Para Scripts e Linguagens de Servidor (Python, Node.js, C, Java, PHP, Bash):**
   - Navegue até o módulo desejado no terminal e rode o experimento:
     ```bash
     # Exemplo Python
     python "LOGICA DA PROGRAMACAO/Python/Modulo_01_Fundamentos_e_Sintaxe_Python/experimento_pratico.py"

     # Exemplo Node / JavaScript
     node "LOGICA DA PROGRAMACAO/JavaScript/Modulo_01_Sintaxe_e_Logica_Basica/experimento_pratico.js"

     # Exemplo C (Compilando com GCC)
     gcc "LOGICA DA PROGRAMACAO/C/Modulo_01_Fundamentos_e_Compilacao/experimento_pratico.c" -o lab_c && ./lab_c
     ```
