## 📖 Sobre a Tech Academy & Laboratório de Código

O repositório **Estudos** evoluiu para uma **plataforma educacional e biblioteca tecnológica vivencial (*Modern Developer Knowledge Hub & Tech Lab*)**, concebida para documentar, estruturar e consolidar a maestria em engenharia de software contemporânea, cibersegurança, automação de sistemas e arquitetura web.

Em resposta às exigências do mercado e integrando as competências já validadas no ecossistema de projetos de **Carlos Guedes** (como o *ERP Biblioteca*, *Color Harmony Engine*, *CommitCraft CLI*, *DevEnv Doctor* e laboratórios de *Entropia e Cibersegurança*), este repositório foi reestruturado em **11 Trilhas de Especialização**. Cada trilha conta com **70+ aulas organizadas progressivamente em 7 Módulos de Maestria**, somando mais de **770 Aulas** com teoria científica, boas práticas corporativas e laboratórios interativos de código.

## 🏗️ Arquitetura Modular de Conhecimento (Estrutura 7x10)

Para garantir que cada uma das 11 trilhas ofereça uma profundidade técnica acadêmica e corporativa, todas foram organizadas na arquitetura padrão de **7 Módulos Progressivos**, onde cada módulo abrange exatamente **10 Aulas Práticas**:

```text
estudos/
├── HTML/
│   ├── GUIA_E_EMENTA_70_AULAS.md              # Ementa detalhada e objetivos didáticos das 70 Aulas
│   ├── Modulo_01_Iniciante_Fundamentos/       # Aulas 01 a 10: Semântica, DOCTYPE e Tags Essenciais
│   ├── Modulo_02_Formularios_e_Interatividade/ # Aulas 11 a 20: Validações Nativas, Modais e Acessibilidade
│   ├── Modulo_03_Multimidia_e_Graficos/       # Aulas 21 a 30: SVG Nativo, Canvas 2D/3D e Open Graph SEO
│   ├── Modulo_04_Web_APIs_e_Armazenamento/    # Aulas 31 a 40: LocalStorage, IndexedDB e Web Workers
│   ├── Modulo_05_Acessibilidade_WCAG_ARIA/    # Aulas 41 a 50: WAI-ARIA, Screen Readers e APCA
│   ├── Modulo_06_Performance_e_Web_Components/# Aulas 51 a 60: Shadow DOM, Custom Elements e Core Web Vitals
│   └── Modulo_07_Projetos_Reais_e_Maestria/   # Aulas 61 a 70: Projeto Final de Landing Page Acessível
├── CSS/
│   ├── GUIA_E_EMENTA_70_AULAS.md              # Guia e Ementa do Módulo de Design e Arquitetura Visual
│   ├── Modulo_01_Fundamentos_e_Selecão/       # Aulas 01 a 10: Especificidade, Box Model e Variáveis
│   └── ... (Módulos de Flexbox, Grid Layout, Design Tokens, Glassmorphism, Animações e BEM)
├── LOGICA DA PROGRAMACAO/
│   ├── JavaScript/                            # 7 Módulos / 70 Aulas de JS ES6+ e Big O Notation
│   ├── TypeScript_React_NextJS/               # 7 Módulos / 70 Aulas do Stack Corporativo e ERP
│   ├── Python/                                # 7 Módulos / 70 Aulas de Automação e Entropia de Senhas
│   ├── C/                                     # 7 Módulos / 70 Aulas de Ponteiros e Alocação Dinâmica
│   ├── JAVA/                                  # 7 Módulos / 70 Aulas de JVM, Streams e Design Patterns
│   └── PHP/                                   # 7 Módulos / 70 Aulas de PDO, MVC e Autoloading PSR-4
├── BANCO_DE_DADOS_SQL_E_PRISMA/               # 7 Módulos / 70 Aulas de SQL Relacional e Prisma ORM
├── GIT_LINUX_E_TERMINAL_CLI/                  # 7 Módulos / 70 Aulas de Shell Script, Docker e Aliases
└── HACKING ÉTICO/                             # 7 Módulos / 70 Aulas de Pentest, WPA2/WPA3 e OWASP
```

Dentro de cada pasta de módulo (`Modulo_XX_...`), você encontrará:
1. `TEORIA_E_PRATICA_DO_MODULO.md`: Resumo científico dos fundamentos, melhores práticas de mercado e laboratório de código consolidado.
2. `pratica_laboratorio.[ext]`: Arquivo de código autônomo na linguagem nativa (`.html`, `.css`, `.js`, `.py`, `.c`, `.java`, `.php`, `.sql`, `.sh`) pronto para compilação ou execução no terminal ou browser.

## 🚀 Como Executar os Laboratórios Práticos

1. **Clone o Repositório no seu Terminal:**
   ```bash
   git clone https://github.com/carlosguedes-dev/estudos.git
   cd estudos
   ```

2. **Para Laboratórios Web (HTML5, CSS3, JavaScript):**
   - Abra a pasta no Visual Studio Code e utilize a extensão **Live Server**.
   - Ou abra os arquivos `pratica_laboratorio.html` diretamente em seu navegador preferido.

3. **Para Scripts e Linguagens de Servidor (Python, Node.js, C, Java, PHP, Bash):**
   - Navegue até o módulo desejado no terminal e execute o laboratório:
     ```bash
     # Exemplo Python
     python "LOGICA DA PROGRAMACAO/Python/Modulo_01_Fundamentos_e_Sintaxe_Python/pratica_laboratorio.py"

     # Exemplo Node / JavaScript
     node "LOGICA DA PROGRAMACAO/JavaScript/Modulo_01_Sintaxe_e_Logica_Basica/pratica_laboratorio.js"

     # Exemplo C (Compilando com GCC)
     gcc "LOGICA DA PROGRAMACAO/C/Modulo_01_Fundamentos_e_Compilacao/pratica_laboratorio.c" -o lab_c && ./lab_c
     ```
